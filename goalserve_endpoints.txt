Tikianaly Tennis — Local Backend Endpoints
==========================================
Server runs on: http://localhost:7824
Start with: node server.js

All endpoints listed below call through the LOCAL Node.js proxy.
The proxy handles CORS, GZIP compression, caching, and API key injection.
All times are UTC. All feeds append ?json=1 automatically.

Endpoint Pattern: http://localhost:7824/api/<path>?<params>

==============================
1. Live Scores  [Cache: 5s]
==============================
Today:           GET  /api/tennis_scores/home?json=1
By Day (±N):     GET  /api/tennis_scores/d-1?json=1         (0=today, -1=yesterday, 1=tomorrow, range: d-7 to d7)
Single Match:    GET  /api/tennis_scores/match?id=[MATCH_ID]&json=1
By Category:     GET  /api/tennis_scores/home?cat=[CAT_ID]&json=1

--- ITF Live ---
ITF Livescore:   GET  /api/tennis_scores/itf?json=1
ITF Today:       GET  /api/tennis_scores/itf_today?json=1
ITF Tomorrow:    GET  /api/tennis_scores/itf_d1?json=1

--- Table Tennis ---
TT Live:         GET  /api/tennis_scores/tt_live?json=1
TT Today:        GET  /api/tennis_scores/tt_today?json=1
TT Tomorrow:     GET  /api/tennis_scores/tt_d1?json=1

==============================
2. Game Stats  [Cache: 30s]
==============================
Today Stats:     GET  /api/tennis_scores/home_gamestats?json=1
Yesterday Stats: GET  /api/tennis_scores/d-1_gamestats?json=1

==============================
3. Point-by-Point  [Cache: 60s]
==============================
Today P2P:       GET  /api/tennis_scores/home_p2p?json=1
Yesterday P2P:   GET  /api/tennis_scores/d-1_p2p?json=1

==============================
4. Tournaments  [Cache: 3h for leagues, 1h for fixtures/draw]
==============================
Leagues List:    GET  /api/tennis_scores/leagues?json=1
ATP Tournaments: GET  /api/tennis_scores/atp_tournaments?json=1
WTA Tournaments: GET  /api/tennis_scores/wta_tournaments?json=1
Fixtures:        GET  /api/tennis_scores/[TOURNAMENT_ID]?json=1
Draw:            GET  /api/tennis_scores/[TOURNAMENT_ID]-draw?json=1

==============================
5. Schedules  [Cache: 1h]
==============================
ATP Singles:     GET  /api/tennis_scores/atp_singles_shedule?json=1
WTA Singles:     GET  /api/tennis_scores/wta_singles_shedule?json=1
ATP Doubles:     GET  /api/tennis_scores/atp_doubles_shedule?json=1
WTA Doubles:     GET  /api/tennis_scores/wta_doubles_shedule?json=1
Challenger Men:  GET  /api/tennis_scores/challenger_shedule?json=1
Challenger Women:GET  /api/tennis_scores/challenger_women_shedule?json=1
ITF Men Singles: GET  /api/tennis_scores/itf_men_singles_shedule?json=1
ITF Men Doubles: GET  /api/tennis_scores/itf_men_doubles_shedule?json=1
ITF Women:       GET  /api/tennis_scores/itf_women_singles_shedule?json=1
Teams Men:       GET  /api/tennis_scores/teams_men_shedule?json=1
Teams Women:     GET  /api/tennis_scores/teams_women_shedule?json=1

==============================
6. Rankings  [Cache: 6h — updated every Monday 08:00 UTC]
==============================
ATP Singles:     GET  /api/tennis_scores/atp?json=1
WTA Singles:     GET  /api/tennis_scores/wta?json=1
ATP Race:        GET  /api/tennis_scores/atp_race?json=1
WTA Race:        GET  /api/tennis_scores/wta_race?json=1
ATP Doubles:     GET  /api/tennis_scores/atp_doubles?json=1
WTA Doubles:     GET  /api/tennis_scores/wta_doubles?json=1
ATP Live:        GET  /api/tennis_scores/atp_live?json=1
WTA Live:        GET  /api/tennis_scores/wta_live?json=1
ATP Race Live:   GET  /api/tennis_scores/atp_race_live?json=1
WTA Race Live:   GET  /api/tennis_scores/wta_race_live?json=1
ATP Doubles Live:GET  /api/tennis_scores/atp_doubles_live?json=1
WTA Doubles Live:GET  /api/tennis_scores/wta_doubles_live?json=1

  Movement values: "same" | "up" | "down"  (never anything else)

==============================
7. Player Profile  [Cache: 6h — updated every Monday 08:00 UTC]
==============================
Profile:         GET  /api/tennis_scores/profile?id=[PLAYER_ID]&json=1

==============================
8. Head-to-Head  [Cache: 1h]
==============================
H2H:             GET  /api/tennis_scores/h2h_[PLAYER1_ID]-[PLAYER2_ID]?json=1
  (BOTH IDs required — never call with a single player ID)

==============================
9. Pregame Odds  [Cache: 30s full / 10s with ts=]
==============================
All Odds (Full): GET  /api/getodds/soccer?cat=tennis_10&json=1
Odds Delta (ts): GET  /api/getodds/soccer?cat=tennis_10&ts=[TIMESTAMP]&json=1
By Match:        GET  /api/getodds/soccer?cat=tennis_10&match=[MATCH_ID]&json=1
By League:       GET  /api/getodds/soccer?cat=tennis_10&league=[LEAGUE_ID]&json=1
By Bookmaker:    GET  /api/getodds/soccer?cat=tennis_10&bm=[BM_IDS]&json=1
By Market:       GET  /api/getodds/soccer?cat=tennis_10&market=[MARKET_ID]&json=1
By Date Range:   GET  /api/getodds/soccer?cat=tennis_10&date_start=dd.MM.yyyy&date_end=dd.MM.yyyy&json=1
Markets Dict:    GET  /api/tennis_scores/pregame_markets?json=1
Bookmakers Dict: GET  /api/tennis_scores/pregame_bookmakers?json=1
  NOTE: Odds are ONLY valid for status = "Not Started" matches.
        Always filter out stop="True" on type, bookmaker, total, or handicap nodes.

==============================
10. Historical Data
==============================
Season Results:  GET  /api/tennis_scores/[LEAGUE_ID]-[YEAR]?json=1
Historical P2P:  GET  /api/tennis_scores/[LEAGUE_ID]-[YEAR]_p2p?json=1
Historical Stats:GET  /api/tennis_scores/[LEAGUE_ID]-[YEAR]-stats?json=1
  Get LEAGUE_ID from the leagues endpoint first — never guess or hardcode.

==============================
11. WebSocket (Real-Time Live Scores)
==============================
WS URL:          ws://localhost:7824/
Subscribe:       { "action": "subscribe",   "url": "http://localhost:7824/api/tennis_scores/home?json=1" }
Unsubscribe:     { "action": "unsubscribe", "url": "http://localhost:7824/api/tennis_scores/home?json=1" }
Server Push:     { "type": "update", "url": "...", "payload": { ...JSON data... } }

==============================
12. Cache Analytics
==============================
GET  http://localhost:7824/cache-stats
Returns the list of all active cached URLs with TTL remaining and size in KB.
